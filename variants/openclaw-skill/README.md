# Tuya Home — OpenClaw skill variant

Drop the `tuya-home/` folder into your OpenClaw skills directory. Set `TUYA_API_KEY` in the environment.

See `tuya-home/SKILL.md` for usage.

Requirements: Python 3 and the `requests` package (`pip install requests`), which
the scripts under `tuya-home/scripts/` use for the HTTPS calls. The Cindy plugin
and the MCP variant need no third-party packages.
