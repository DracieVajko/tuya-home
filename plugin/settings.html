Tuya API key
Checking… Create the key at tuya.ai/developer (international) or tuyasmart.com (China mainland); API docs: tuya.ai/developer/docs. The key is stored by Cindy, never by this plugin: it is only injected into requests to Tuya's API.
Data centre
A Tuya key only works in the data centre where the account is registered, and this plugin cannot read the key to see which one that is. Automatic detection asks the remembered centre first, then the others in turn, retrying a blocked request once before moving on. Pin a centre here if the account is region-locked.
Advanced — home structure
Off by default. With it on, the assistant may also do three things: create a room, move one device into a room, and unbind (remove) a device. Unbinding deletes the device from your Tuya account and from the Tuya app. That is permanent from here: the device disappears from the app and has to be paired again to come back. Scenes that pointed at it stop controlling anything. It requires the key to be allowed to manage this home; an ordinary end-user key (sk-) is refused by Tuya (1010/1108), and the plugin then reports the refusal instead of retrying. Reading state, switching devices and renaming are not affected by this setting either way.
